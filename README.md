# pg-util

Утилита командной строки, которая позволяет выполнять массовый бэкап и удаления Баз Данных Postgres. Основана на стандартном клиенте Postgres.

Утилита использует комманду `pg_dump` являющуюся частью стандартного пакета `postgresql-client-common`. В частности, для корректной работы интеграционных тестов рекомендуется клиент PostgreSQL версии >= 16. 

## Использование:

```
  ./pg-util --operation=remove|backup --databases=[db1,db2...] [connection-option...]
```

## Опции:

**-o, --operation=OPERATION**: Тип операции. 
Допустимые значения: **backup** (создание бэкапов баз данных) или **remove** (удаление баз данных). Обязательный параметр.

**-d, --databases=DB1,DB2,...**: Список баз данных для обработки. 
Поддерживает регулярные выражения POSIX. Можно указывать как конкретные имена баз данных, так и шаблоны для массового выбора. Обязательный параметр.

**-h, --host=HOSTNAME**: Имя хоста сервера PostgreSQL. По умолчанию берется из переменной окружения **PGHOST**.

**-p, --port=PORT**: Номер порта сервера PostgreSQL. По умолчанию берется из переменной окружения **PGPORT**.

**-U, --username=USERNAME**: Имя пользователя PostgreSQL. По умолчанию берется из переменной окружения **PGUSER**.

**-W, --password=PASSWORD**: Пароль пользователя PostgreSQL. По умолчанию берется из переменной окружения **PGPASSWORD**.

**--help**: Вывести справку по использованию утилиты.

## Переменные окружения:
Перечисленные переменные окружения не являются обязательными.
Программа использует их в качестве значений по умолчанию (для подключения к Postgres) и опций логирования:

**PGHOST**: Адрес сервера PostgreSQL.

**PGPORT**: Порт сервера PostgreSQL.

**PGUSER**: Имя пользователя PostgreSQL.

**PGPASSWORD**: Пароль пользователя PostgreSQL.

**LOGLEVEL**: Уровень логирования. Допустимые значения: **DEBUG**, **INFO**, **WARN** (по умолчанию), **ERROR**.
